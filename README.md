# Cipher

Secure realtime messaging for private conversations, roles, and permission-gated media.

The first milestone is a proposed closed-alpha desktop messaging vertical slice. Message bodies are end-to-end encrypted; calls, general attachments, multi-device use, multi-gateway routing, and Cipher Pay integration are outside the alpha. The release decisions and acceptance journey are recorded in [ADR-0001](docs/adr/0001-closed-alpha-scope.md).
