# Security

Do not report a suspected vulnerability in a public issue.

Use [GitHub private vulnerability reporting](https://github.com/connorlhunter/cipher/security/advisories/new). Include the affected version or commit, reproduction steps, expected impact, and any suggested fix. Do not include real user content or credentials.

Cipher is in private MVP development. Only the current `main` branch is supported, and there is no public bug bounty or guaranteed response time.
